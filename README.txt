OUR LOVE STORY — Pro bilingual romantic website
=================================================

Files:
- index.html  : website content and layout
- style.css   : burgundy/cream design, responsive layout, illustrated swans
- script.js   : English/French language switch and interactive 6-question quiz

Open locally:
1. Extract the ZIP.
2. Open the extracted folder in VS Code (File > Open Folder).
3. Open index.html and choose "Open with Live Server", or run `npx --yes live-server` in this folder.

Music:
The site includes a music panel with a YouTube search link for Charles Aznavour's "For me... formidable".
It does not bundle copyrighted music or autoplay audio. The visitor can click to listen, and YouTube provides playback controls.

Personalize:
- Edit the English/French letter in index.html.
- Edit the six quiz questions and answers in script.js.
- Change colors in :root at the top of style.css.

Publish:
Upload this folder to GitHub Pages or Vercel to get a shareable public URL.
